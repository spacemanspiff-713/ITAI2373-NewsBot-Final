# AI and External Tool Assistance Disclosure

AI-assisted tooling supported planning, debugging, refactoring, documentation drafting, and test iteration. The project’s final code, notebooks, and local outputs were reviewed and executed in the project environment. AI-generated prose and model-generated NLP output were not treated as independently verified facts.

External libraries/models include scikit-learn, spaCy, VADER Sentiment, TextBlob, NetworkX, Streamlit, Flask, Hugging Face Transformers, Sentence-Transformers, langdetect, and optional deep-translator/MarianMT adapters. Their use is visible in requirements, imports, and documentation. The project uses no paid LLM API for core analysis or response generation.

All claims in the reports distinguish measured local evaluation from assumptions. Translation, summary, similarity, sentiment, and entity outputs remain subject to human review.
